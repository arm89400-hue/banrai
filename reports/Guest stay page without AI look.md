# Turn the stay dashboard into a host's letter

The "my stay" page looks AI-made because it is laid out like a SaaS dashboard: a slideshow at the top, a large "hero metric" countdown, a bento grid of identical white rounded cards with an icon beside each heading, a progress bar, and pill chips. Designers writing in 2025-2026 name almost every one of these as a tell. The fix is to change the page's structure, not to restyle it. Make it read like a single scrolling note from a named owner. It should open with the guest's dates and a plain sentence about what is owed, then cover how to arrive at this particular gate, then the chat, then what is actually ripe on the farm during those dates, and finally short house notes. The sections should be separated by headings, spacing and dividers, not a box per item. This also helps usability. Airbnb, guidebook vendors and real farm arrival sheets all put arrival facts first and write in the host's voice, and one vendor case study found that guests often stop after the first step of a multi-step flow, which argues against hiding the essentials behind phone tabs. On type, the evidence favours a looped Thai face for the instructional text, which suits the families with older members who stay at farmstays, with loopless kept for labels, prices and buttons. The research has one main limit: no controlled study shows which fixes users actually see as "less AI". The list of tells is a consensus among practitioners, and the tells keep changing, so swapping one trendy default for another will not solve the problem.

## Nearly every element of the current page is a named AI tell

Independent sources describe the same shortlist. "Identical card grids", where repeated icon-plus-heading-plus-text cards give every point equal weight, are the most-cited tell. The suggested fix is to "group related ideas and vary the layout" ([impeccable.style](https://impeccable.style/slop)). Jeff Humble argues that **cards should be reserved for "things that genuinely benefit from the affordance of a bounded, interactive object"** ([Fountain Institute](https://www.thefountaininstitute.com/blog/signs-vibe-coded-ui)). The pixelslop catalogue calls the effect "more container than content" and describes rounded rectangles with generic shadows as "safe, forgettable, could be any AI output from any prompt" ([pixelslop](https://cdn.jsdelivr.net/npm/pixelslop@0.3.8/dist/skill/resources/ai-slop-patterns.md)). Anthropic's own frontend-design guidance names the same thing the "SaaS card kit": identical rounded cards, one radius for everything, and the same soft grey shadow ([Anthropic SKILL.md](https://raw.githubusercontent.com/anthropics/claude-code/main/plugins/frontend-design/skills/frontend-design/SKILL.md)). Website-builder vendors are actively promoting bento grids as a 2026 trend, which is part of why they now look generic ([B12](https://www.b12.io/resource-center/website-design/web-design-guide-bento-grids-and-kinetic-typography/)).

The other elements map just as directly. "อีก 33 วัน" set very large is the **"Hero Metric Layout": a big number (48-72px) with a small label, which should appear only when it has context** ([pixelslop](https://cdn.jsdelivr.net/npm/pixelslop@0.3.8/dist/skill/resources/ai-slop-patterns.md)). None of the hospitality sources reviewed uses a countdown as a pattern, so "in 33 days" written next to the dates is as far as the evidence goes. Icons attached to every heading are a variant of the "universal feature list template", and the fix is to drop them or keep them only where they help recognition ([pixelslop](https://cdn.jsdelivr.net/npm/pixelslop@0.3.8/dist/skill/resources/ai-slop-patterns.md); [impeccable.style](https://impeccable.style/slop)). The outline-icon set itself is part of the default stack (shadcn, Lucide, Tailwind) that appears "verbatim in thousands of public repos" ([SaaStr](https://www.saastr.com/gemini-3-solves-one-of-the-biggest-headaches-with-vibe-coding-now-your-site-doesnt-have-to-look-like-it-was-vibe-coded/)). A full-width slideshow is a "generic hero section", "indistinguishable from a template". Pill badges compete with the message and look clickable when they are not ([impeccable.style](https://impeccable.style/slop)). The deeper diagnosis applies to the whole page: an AI-made interface **"treats every screen like a landing page rather than a functional tool"** ([Desai](https://godobject.dev/blog/10-tells-of-slop)). A guest stay page is a tool. The guest comes to it to check a date, an amount, a direction or a message.

These looks share a cause. A July 2026 benchmark of 120 interfaces from five generative UI tools found the outputs "converged in visual appearance and layout" ([Imteyaz et al., arXiv](https://arxiv.org/abs/2607.22928)). The common thread across the tells is decoration that carries no information, plus equal weight everywhere. That gives a practical test, the **swap test**: if replacing a choice with a standard template changes nothing, the choice was a default. A second test asks whether you can point to five specific elements where the product's own signature shows ([interface-design skill](https://www.ui-skills.com/skills/dammyjay93/interface-design)). The current page fails both tests. Without the farm name and photos, nothing on it says "Pak Chong farmstay".

The tells also keep moving. Anthropic's guidance now lists **warm cream backgrounds with a terracotta accent** as a newer AI default, and impeccable.style flags the italic-serif "editorial" headline in the same way ([Anthropic SKILL.md](https://raw.githubusercontent.com/anthropics/claude-code/main/plugins/frontend-design/skills/frontend-design/SKILL.md); [impeccable.style](https://impeccable.style/slop)). Replacing white cards with cream cards and a serif headline would just swap one tell for another.

## Real guest pages read like itineraries and arrival sheets, not dashboards

Airbnb is the only major brand whose post-booking structure is publicly documented. Its 2025 Trips tab is "an advanced travel itinerary with a schedule of your trip", with check-in as one timeline entry among others and messaging in a separate tab ([Airbnb Newsroom](https://news.airbnb.com/product-releases/airbnb-2025-summer-release/)). Its arrival guide follows a fixed order: **check-in, directions, check-in method, Wi-Fi, house manual, house rules, check-out, guidebook** ([Touch Stay](https://touchstay.com/blog/airbnb-arrival-guide)). Airbnb also tells guests to save the instructions offline in case they lose signal on the road ([Airbnb Help](https://www.airbnb.com/help/article/41)). Small farm and glamping sheets are blunter and more useful still. One New Zealand camp gives turn-by-turn directions, warns 2WD drivers about a steep track, and ends with **"Please text Pip when you have arrived and she will meet you there"** ([Canopy Camping](https://canopycamping.co.nz/sites/default/files/2019-09/CAMP%20KEKERENGU%20INFO%20SHEETv4.pdf)). A US farm keeps the stopping point separate from parking and gives a check-in window ([Harvest Hosts](https://harvesthosts.com/hosts/new-york/gLiiKXbXPiZpPrXZmUtY)). A South African farm stay is reviewed for warning about 38 km of gravel, no cell reception and no takeaway nearby ([Kayak](https://www.kayak.com/Graaff-Reinet-Hotels-Waterval-Farmstay.2301197.ksp)).

For บ้านไร่ของพ่อ 344, this suggests the following order: dates, nights and room; what is owed and how to pay; how to get there, ending with a photo of the actual turn-off or gate and a line in the owner's words ("ส่งข้อความหาเราตอนถึงหน้าประตูนะคะ", "message us when you reach the gate"); the chat; what is happening on the farm during their dates; and house notes and check-out. Airbnb holds access details back until 48 hours before arrival. A family homestay with someone at the gate has nothing to hide, so it can show everything at once and move "arrival" to the top as the date gets close. Guidebook vendors push visuals hardest. Touch Stay calls photos of the parking spot "essential for neurodiverse guests" ([Touch Stay](https://touchstay.com/blog/airbnb-arrival-guide)). A real photo of the gate also fixes the generic slideshow, because it is useful and could only belong to this farm.

No public source shows how a hotel displays a remaining balance. That leaves plain clarity as the standard: the amount, the deadline and the two ways to pay (online now, or at the farm), written as one or two sentences. The guidance on metrics agrees: a number needs context, and a status written out ("มัดจำแล้ว ฿1,250 เมื่อ 3 ต.ค.", deposit of ฿1,250 paid on 3 Oct) beats a coloured bar or pill ([pixelslop](https://cdn.jsdelivr.net/npm/pixelslop@0.3.8/dist/skill/resources/ai-slop-patterns.md); [Fountain Institute](https://www.thefountaininstitute.com/blog/signs-vibe-coded-ui)). A progress bar suggests a process with stages. A deposit is two facts: what has been paid and what is left.

The tab question deserves a fair hearing on both sides. In a Canary review, 75% of arrivals used pre-registration, but **"many [complete] only the first step"** of a multi-step flow ([HotelTechReport](https://hoteltechreport.com/reviews/q39wv19knwv5)). That argues against splitting booking, chat and activities into three phone tabs, because a guest who never taps "กิจกรรม" never sees what is ripe. On the other side, Airbnb does keep messaging as its own tab ([Airbnb Newsroom](https://news.airbnb.com/product-releases/airbnb-2025-summer-release/)), because chat is a different kind of task: ongoing, full-screen and keyboard-heavy. The balance is a single scrolling page for reading, with the chat opened from a clear "message us" entry that takes it full screen on phones and sits as a side column on computers.

## Personal comes from specifics and one signed voice, not ornament

The cheapest sign of a real host is a **welcome note signed by a named person**. Six Senses lists a welcome letter among the arrival amenities its Guest Experience Makers prepare ([Six Senses Ibiza](https://sixsensesibiza.teamtailor.com/jobs/6096443-guest-experience-maker-manager-six-senses-ibiza)), and the "text Pip" sheet shows the same instinct at the scale of a small farm. Touch Stay recommends mentioning something from the guest's own booking and giving tips that match their interests ([Touch Stay](https://touchstay.com/blog/best-guest-communication-tactics-between-booking-and-arrival)). The opposite is easy to spot: a boutique-hotel letterhead template with a gold header, "Dear Guest" and a fake handwritten signature line ([PlatoForms](https://templates.platoforms.com/pdf/boutique-hotel-guest-services-letterhead)). Beaumier hotels described their old pre-arrival flow as "a static web experience that felt disconnected from the premium service guests expected" ([HotelTechReport](https://hoteltechreport.com/fr/success-stories/operations/canary/beaumier)).

Voice matters as much as layout, especially in Thai. One Thai writing guide warns that AI-drafted Thai sounds stiff and formal, and that **overusing ครับ/ค่ะ reads as "stiff, robotic"** ([skills.sh](https://www.skills.sh/clawic/skills/thai)). The particle follows the speaker's gender, so a female owner writes ค่ะ throughout and never mixes in ครับ ([HoneyKids Asia](https://honeykidsasia.com/thailand/ka-vs-krab-thailand/)). นะ softens a line without adding formality ([Ling](https://ling-app.com/?p=513089)). A Thai rental-copy guide recommends opening with an image rather than adjectives ([SmartOrder](https://www.smartorder.ai/resources/th/blog/perfect-your-rental-descriptions-for-more-bookings-th/)). In practice that means "มะม่วงหลังบ้านเริ่มสุกแล้วนะคะ" (the mangoes behind the house are starting to ripen) rather than "สัมผัสประสบการณ์ธรรมชาติสุดพิเศษ" (experience special nature), and directions given with landmarks such as the 7-Eleven, the temple or the big tree. The guidance on copy tells also applies here: no "Welcome to your Dashboard ✨", and no headings that repeat the label above them ([Desai](https://godobject.dev/blog/10-tells-of-slop); [impeccable.style](https://impeccable.style/slop)). The pill chips in the chat are the one place where steelmanning helps. Suggested questions do save typing, and the tell lies in their pill styling, not their purpose. Two or three questions written in a guest's real words and set as plain text links would keep the function without the template look.

For local character, the strongest Khao Yai reference is Roukh Kiri in Pak Chong, designed by Onion. It has hand-sketched villas "just like a child's drawing", shingled teng-wood ceilings, rattan, crochet and a sala, all against a palette **"pared back to austere whites and beiges"**, with fruit trees feeding the kitchen ([City Nomads](https://citynomads.com/designs-on-asia-roukh-kiri-khao-yai-a-farmhouse-style-resort-in-thailand-where-simplicity-meets-luxury/)). The lesson is a quiet base where real materials and real crops carry the warmth, not painted-on "Thai pattern" decoration. If the page uses a motif at all, the obvious candidate is pha khao ma, the checked cloth found in every region, which Thailand put forward for UNESCO heritage status in 2023 ([Thailand PRD](https://thailand.prd.go.th/en/content/category/detail/id/48/iid/163229)). It should be sampled from the farm's own cloth and used once, for example as a thin divider. A stock "Thai weaving border" is exactly the generic look to avoid. "Spend boldness in one place" is the governing rule ([Anthropic SKILL.md](https://raw.githubusercontent.com/anthropics/claude-code/main/plugins/frontend-design/skills/frontend-design/SKILL.md)), and on this page the obvious bold element is the ripe-fruit section, because it changes with the guest's dates and no template could produce it.

## Looped Thai for the words guests must follow, loopless for labels

IBM Plex Sans Thai throughout is not a classic tell like Inter, but it is one undifferentiated choice applied to every kind of text. The best recent evidence is Typotheque's 2024 Bangkok experiments, with 41, 38 and 139 participants. **Looped Thai was read slightly but significantly faster in continuous reading, was seen as more readable at every age, and was linked with "classical" and "formal".** Loopless read as "modern" and was preferred by younger readers only where there was little text ([Typotheque](https://www.typotheque.com/research/effects-of-loops-in-thai)). One caveat: the ATypI abstract says reading performance was not affected by loops, which conflicts with Typotheque's own write-up, and the author calls the results preliminary ([ATypI](https://atypi.org/?p=34632)). The perception result is the robust part, and on a page full of directions and house notes, perceived readability is what matters. The lowest-risk change stays inside the current family: **IBM Plex Sans Thai Looped** for directions, the welcome note and house notes ([Fontsource](https://fontsource.org/fonts/ibm-plex-sans-thai-looped/about)), with the existing loopless Plex (or Anuphan, which is built from Plex outlines) for dates, prices, buttons and headings ([Google Fonts](https://fonts.google.com/specimen/Anuphan/about)). A handwritten face such as Cadson Demak's Charm could appear once, on the owner's signature line ([Google Fonts](https://fonts.google.com/specimen/Charm/about)). Using it for whole sections would look like a costume.

The mechanics matter too. Thai marks stack on up to three sides of a consonant ([W3C thai-lreq](https://www.w3.org/TR/thai-lreq/)), and tight line-heights clip words like ขึ้น ([Discourse](https://meta.discourse.org/t/in-title-bar-n-and-similar-diacriticals-are-clipped-in-linux/67303)). Readers in one study preferred line spacing of about 1.5x or more ([White Rose thesis](https://etheses.whiterose.ac.uk/id/oai_id/oai:etheses.whiterose.ac.uk:9027)). Exact values beyond that are convention rather than a standard, because W3C leaves line-height open. Western digits remain the everyday choice for prices and dates ([Transparent Language](https://blogs.transparent.com/thai/?p=963)). Thai digits signal heritage and could appear once as a stamped house number, never in an amount the guest has to pay. Letter-spaced all-caps eyebrow labels have no Thai equivalent, because tracking is not used in Thai running text ([W3C](https://www.w3.org/TR/2024/DNOTE-thai-lreq-20240430/)), so any small spaced-out labels above headings look doubly imported.

## Prioritised changes for the stay page

The order below puts structural changes that remove the most visible tells and improve usability first, and polish last. Items 1-4 change what the page is. Items 5-10 change how it reads.

| # | Change | Replaces | Why |
|---|---|---|---|
| 1 | Remove the bento grid. Make the page one column of sections separated by headings, spacing and thin dividers. Keep a bounded box only for things you tap (the pay button, the chat entry). | Identical white rounded cards | The most-cited AI tell; "more container than content" |
| 2 | Open with a short note signed by the named owner (photo, first person, one particle), then the dates as a sentence: "เจอกันวันศุกร์ 21 พ.ย. – อาทิตย์ 23 พ.ย. · 2 คืน · ห้อง…" ("see you Fri 21 Nov to Sun 23 Nov · 2 nights · room…"), with "อีก 33 วัน" (in 33 days) in normal text size beside it | Big countdown hero metric | The hero-metric tell; no source uses countdowns; welcome letters are the established habit at both luxury and small-host level |
| 3 | Replace the slideshow with one fixed, captioned photo that does a job: the gate or turn-off, then the house | Full-width photo slideshow | Generic hero; arrival photos are the visual guidebooks push hardest |
| 4 | Put the payment status in plain words: "มัดจำแล้ว ฿X เมื่อ [date] · เหลือ ฿Y — จ่ายออนไลน์ตอนนี้ หรือจ่ายที่บ้านไร่วันเข้าพัก" ("deposit of ฿X paid on [date] · ฿Y left: pay online now, or at the farm on arrival"), with a single primary button | Progress bar | A number needs context; no stage process exists |
| 5 | On phones, drop the three segmented tabs. Use one scrolling page with a short "jump to" line under the dates, and a fixed "ทักเรา" (message us) button that opens the chat full screen. On computers, put the chat in a right-hand column beside the reading page. | การจอง / แชท / กิจกรรม tabs | Guests stop after step 1; chat is a separate kind of task, as on Airbnb |
| 6 | Add a "how to get here" section written in the owner's voice: landmarks, road notes, check-in window, "message us at the gate", a map link, and a save-offline hint | Missing or generic arrival info | First in Airbnb's order; farm sheets lead with this |
| 7 | Make "ripe during your stay" the page's one bold element: fruit and activities filtered to the guest's dates, with real photos and the owner's line about each | Activities card | Specific to the farm and the dates; "spend boldness in one place" |
| 8 | Set body text in IBM Plex Sans Thai Looped (16-18px, generous line-height, no clipping), keep loopless Plex or Anuphan for labels and prices, and allow one handwritten signature line | Plex Sans Thai everywhere | Looped is perceived as more readable, especially by older guests |
| 9 | Remove the heading icons. Keep an icon only where it speeds recognition (phone, map pin, Wi-Fi). | Outline icon beside every heading | Icon-per-heading tell; default icon set |
| 10 | Cut the chat to 2-3 suggested questions in a guest's real words, shown as plain text links. Rewrite all page copy in one named voice with no marketing adjectives, keep house notes short, and use Western digits for every amount. | Pill quick-question chips; generic copy | Pills read as template; stiff Thai reads as machine-made |

Before showing the owner, run the swap and signature tests on the result. If you can point to five things only this farm could have (the gate photo, the owner's signed note, this month's fruit, the landmark directions, the cloth-sampled divider), the page has moved from template to authored. Keep the palette question open as well: if the new base drifts to cream with a terracotta accent, it has picked up the 2026 version of the same problem.

## Conclusion

Removing tells is necessary but not enough. Every deletion needs something real to fill the gap. A stay page has an advantage most AI-styled screens lack: it is about one guest, on specific dates, at one specific place, so almost every block can be filled with information no template has. The countdown becomes their dates. The progress bar becomes their payment. The slideshow becomes their gate. The bento tiles become what will actually be ripe while they are there. The research also shows that the anti-AI fixes and the usability fixes are the same changes. Arrival first, plain status sentences, one scrolling page and a signed host voice are what both camps recommend, so the owner does not have to trade ease of use for character.

Two things remain uncertain. No one has measured which of these changes guests actually perceive as "less AI", and the Thai-specific evidence comes from one preliminary type study. That makes the owner's and a few real guests' reactions to a mock-up the deciding test, ahead of any checklist.
